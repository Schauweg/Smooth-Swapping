# Smooth Swapping

[![Modrinth Downloads](https://img.shields.io/modrinth/dt/smooth-swapping?logo=modrinth&logoColor=%2300AF5C&color=%2300AF5C)](https://modrinth.com/mod/smooth-swapping)
[![CurseForge Downloads](https://img.shields.io/curseforge/dt/513689?logo=curseforge&logoColor=%23F16436&color=%23F16436)](https://www.curseforge.com/minecraft/mc-mods/smooth-swapping)

Smooth Swapping is a client-side mod that animates item movement inside inventories.

![inventory animation](https://media.forgecdn.net/attachments/655/59/inventory.gif)

## Features

- Items fly smoothly from slot to slot instead of jumping
- Picking items up with the cursor and putting them down is animated too (can be turned off for simple clicks)
- Works no matter what moved the items: clicks, shift-clicks, hoppers, sorting mods or the server
- Items moving into and out of bundles and shulker boxes are animated
- Compatible with Sophisticated Backpacks and other mods based on Sophisticated Core

## Settings

![settings menu](https://media.forgecdn.net/attachments/655/61/settings.gif)

- Toggle to enable and disable the mod
- Animation mode: every swap takes the same time, or every item moves at the same speed
- Slider to adjust the animation speed
- Toggle to animate simple cursor clicks (picking up and putting down a stack)
- Graph to change the animation curve
    - Right-click on an empty space to create a new curve point
    - Left-click and drag a point to move it. The first and last point can't be moved
    - Right-click on a point to delete it
- Small inventory to preview your animation

On Fabric, the settings menu is opened through [Mod Menu](https://modrinth.com/mod/modmenu).
